## 1. 背景与目标

在一台电脑上实时查看并操作华为 Mate 40 Pro 的**整台屏幕**（不是单个 App 的截图），并在网页上完成 Home / Back / 多任务 / 电源 / 音量等反控操作，网页与手机状态实时联动。

核心取舍：**复用成熟开源项目做二次开发，不自研投屏协议栈**；第一版只在本机 `http://127.0.0.1:8000` 运行，架构上预留远程扩展但本期不实现；不 root、不绕过锁屏、不采集 `FLAG_SECURE` / DRM 内容、不在手机安装额外 App。

## 3. 功能需求

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| FR-01 | 整屏镜像 | 手机全屏画面实时投到浏览器；视频/音频与控制走 WebSocket |
| FR-02 | 系统按键反控 | 电源、音量±、返回、主页、多任务；最初在顶部文字栏，后按用户要求隐藏顶栏，统一到右侧工具栏 |
| FR-03 | 触摸反控 | 鼠标点击/拖拽等价于手指触摸，触摸层与画面严格重合 |
| FR-04 | 滚轮与右键 | 滚轮上下滚动手机页面；右键映射 Back，浏览器原生菜单被禁止；Esc 可退出全屏 |
| FR-05 | 设置面板 | 分辨率、帧率、码率、音频、显示语言、界面字体大小/颜色、统计字体大小/颜色、导航条最大尺寸、状态条最大尺寸、导航按钮显示 |
| FR-06 | 分辨率自适应 | 请求 1280 → 1080 → 720 阶梯；检测协商分辨率被大幅降级时自动重启并降一档 |
| FR-07 | 多语言 | 中文/英文；"跟随浏览器"按 `navigator.language` 的 `zh` 前缀判断；静态文本、状态、锁屏/剪贴板提示、tooltip、canvas 统计文字全覆盖 |
| FR-08 | 状态联动 | 每 3 秒轮询设备锁屏/休眠状态，黑屏时给出明确提示 |
| FR-09 | 画面全屏 | 画面左上角图标按钮（tooltip 提示），点击后 `#stream` 铺满视口并隐藏工具栏；画面圆角、白边、间隔保留；再次点击或 Esc 退出 |
| FR-10 | 外观 | 画面圆角 20px、2px 白色描边、上下 2px 间隔；外侧容器无边框/圆角/阴影 |
| FR-11 | 工具栏 | 引擎工具（截图/键盘/鼠标/统计/刷新/复制/粘贴/设置）带文字标签；按键显示模式可为图标/文字/图标&文字；统计与触控位置已交换 |
| FR-12 | 引擎工具 | 截图、键盘捕获、UHID 鼠标键盘、画质统计、触控/方向键切换、刷新、剪贴板双向 |
| FR-13 | 启动编排 | USB 唯一性检查与周期复查、复制 web 资源、启动引擎与桥、就绪等待、信号清理 |
| FR-14 | 反馈与错误处理 | 连接中/已连接/按键已发送/离线/引擎不可用/不安全来源等状态提示 |

## 4. 非功能需求

| 编号 | 需求 | 实现要点 |
| --- | --- | --- |
| NFR-01 | 安全边界 | 引擎与桥只绑定 `127.0.0.1`；桥 CORS 白名单仅 `http://127.0.0.1:8000` 与 `http://localhost:8000`；启动强制断开 Wi-Fi ADB，只认固定 USB 序列号 |
| NFR-02 | 设备与内容限制 | 不 root、不绕过锁屏、不采集 `FLAG_SECURE`/DRM、不安装手机 App；锁屏黑屏只做解释性提示 |
| NFR-03 | 清晰度 | 实测设备屏幕 1152×2376，编码器请求过大时会回退到 512 上限；关闭 `fitToScreen`，显式请求尺寸并按阶梯降级 |
| NFR-04 | 启动健壮性 | 代理环境下 Node `fetch` 不读系统代理，可选 node-pty 下载会超时；启动脚本注入 `NODE_USE_ENV_PROXY` 与 `--use-system-ca` |
| NFR-05 | 浏览器兼容 | WebCodecs 需要安全上下文，普通 HTTP 仅 loopback 可用；`.mjs` 静态服务不支持，浏览器侧统一复制为 `keys.js` |
| NFR-06 | 可维护性 | 引擎作为 GPL-3.0 外部依赖由 `setup` 拉取、不入库；按键码、设置校验、分辨率策略集中在 `shared/keys.mjs`；44 个单元测试 |
| NFR-07 | 易用性 | 设置改动立即生效；tooltip 与文字标签双语；状态栏实时反馈；README 含快速开始、排错与截图 |

## 5. 约束与限制

- 设备与端口固定：USB 序列号 `2FD0221C09004177`，引擎 `8000`，桥 `8100`；换设备需改 `server/adb.mjs` 与 `web/app.js`。
- 引擎是第三方 GPLv3 项目，版本锁定 v0.5.13，仅有 loopback 补丁；升级需改 `ENGINE_TAG` 并重建。
- 远程访问未实现；LAN 上普通 HTTP 无法解码视频，需要自行加 HTTPS 并放宽 CORS/绑定。
- 无进程守护，由启动脚本自己处理清理；`web/`/`shared/` 改动需重启 `npm start` 才会复制。
- 设备编码器的可接受尺寸上限会随状态变化；1280 有时可用、有时必然降级，因此保留自动阶梯而非固定值。

## 6. 最终界面形态

- 顶部导航栏隐藏；系统按键与工具集中在右侧 44px（可倍数调整）窄栏，按钮可切换图标/文字/两者。
- 秩序：电源、音量+、音量−、返回、主页、多任务、截图、键盘、鼠标、**触控、统计**、刷新、复制、粘贴、设置；左上角为全屏图标按钮。
- 画面：圆角矩形 + 2px 白色描边 + 上下 2px 间隔；外侧容器为普通黑底，无边框、圆角、阴影。
- 语言：默认跟随浏览器；中文界面下所有按钮、tooltip、状态与统计文字均为中文。

## 7. 验收与实测结果

| 项目 | 实测结果 |
| --- | --- |
| 分辨率 | 自动阶梯下稳定 `Connected — 522x1080`，画布 522×1080，相对原始 248×512 约 4.4 倍像素量 |

| 滚轮反控 | 设置页 `WLAN` 项 y=549 → 437（下滚）→ 521（上滚），页面本身不滚动 |
| 右键 | contextmenu 在画面与页面其他区域均被拦截 |
| 多语言 | 中文/英文切换、刷新持久化；tooltip、canvas 统计文字均随语言变化 |
| 外观设置 | 字体颜色/大小、导航条/状态条倍数、按钮显示模式均实测生效并与界面字体解耦 |
| 全屏 | 按钮文字切为"退出全屏"、工具栏隐藏、画面放大且保留圆角白边；Esc 退出 |
| 稳定性 | 代理环境下引擎 3 秒内就绪；`npm test` 44/44 通过 |

## 8. 已知遗留与后续方向

**遗留小问题（不阻塞第一版）**

- `lockHint` 的"正在唤醒"文案尚未接 `POST /api/devices/sleep-wake`，目前只是提示。
- 按键处理可能覆盖错误状态（工具条与状态栏的提示优先级）。
- 轮询失败时旧的锁屏提示可能残留。
- `copyWeb` 用文件列表最后一项推断共享文件、子进程缺少 `'error'` 监听、readiness `fetch` 无 `AbortSignal` 等实现细节可加固。

**后续方向**

- 远程访问（HTTPS + CORS/绑定地址放宽 + 鉴权）。
- 多设备切换与设备发现 UI。
- 真实浏览器 Fullscreen API（当前为 CSS 铺满视口的等价实现）。
- 手机端配套 App（当前明确不安装额外 App）。
- 更完整的自动化测试（DOM 层与端到端截图对比）。
